# Описание проекта

Цель проекта — построить модель машинного обучения, предсказывающую **цену
продажи автомобиля** (`Selling_Price`) по его характеристикам: возраст,
рыночная цена, тип топлива, тип коробки передач, пробег, тип продавца и др.

Датасет содержит информацию о 301 объекте автомобили с 9
исходными признаками.

Целевая переменная: `Selling_Price`.

# Описание модулей проекта

### `eda/`
Содержит блокнот разведочного анализа и сохранённые графики.

## Результаты EDA

### Очистка данных

На этапе очистки выполнено:
- удалены полные дубликаты строк (2 записи);
- проверены и обработаны пропущенные значения (в датасете отсутствуют);
- проверены невалидные значения: пробег ≤ 0, цена продажи ≤ 0,
  рыночная цена ≤ 0, отрицательный возраст — таких нет;
- столбец `Year` заменён на **`Car_Age`** (возраст автомобиля);
- зафиксированы выбросы в `Selling_Price` (16 из 299, ~5.4%) — оставлены
  как реальные дорогие автомобили.

### Новые признаки

По результатам EDA сформированы:
- `Car_Age` — возраст автомобиля (заменяет `Year`);
- (по желанию) `Price_Ratio`, `Is_Old`, `Log_Kms` — описаны в выводах
  под графиками.

### Закономерности по графикам

1. **Распределение `Selling_Price`** — правостороннее, есть выбросы (дорогие
   авто). Целевая переменная не нормальна → для линейных моделей полезно
   логарифмирование.

2. **Корреляционная матрица** — сильнее всего с целевой переменной связан
   `Present_Price` (~0.88). `Car_Age` имеет отрицательную корреляцию (~-0.5).
   `Driven_kms` и `Owner` — слабые сигналы.

3. **Цена по категориям** — Diesel и Automatic в среднем дороже Petrol
   и Manual. `Fuel_Type`, `Transmission`, `Selling_type` — информативные
   категориальные признаки.

4. **Цена vs возраст** — чёткая отрицательная зависимость: чем старше авто,
   тем ниже цена. `Car_Age` — сильный числовой предиктор.

5. **Интерактивный график (Plotly)** — почти линейная зависимость
   `Selling_Price` от `Present_Price`. Дорогие авто формируют отдельный
   кластер; Diesel и Automatic чаще встречаются среди дорогих.

### Итоги по признакам

- **Ключевые предикторы:** `Present_Price`, `Car_Age`.
- **Информативные категориальные:** `Fuel_Type`, `Transmission`,
  `Selling_type`.
- **Слабые:** `Driven_kms`, `Owner` — полезны в логарифмированной форме.
- `Car_Name` исключён из финального набора из-за высокой кардинальности
  (~98 уникальных значений), чтобы избежать переобучения.

### Финальный датасет

Очищенный и подготовленный датасет сохранён в двух форматах:
- `data/car_data_clean.csv` — для просмотра;
- `data/car_data_clean.pkl` — для дальнейшей работы (сохраняет типы столбцов).

Размер: **299 строк × 9 столбцов** после One-Hot Encoding.
